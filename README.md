# Práctica 1 - Análisis exploratorio de dataset

El documento utilizado para esta practica es: `survey.csv`

El siguiente dataset se compone de 1258 resgitros y 27 atributos

Las variables que componen el dataset son los siguientes:

  -Informacion personal como la edad, el genero el pais y el estado
  -Contexto laboral tal como si es auto empleado, no esta empleado, trabaja remoto o en una empresa de tecnologia
  -Historial y condicion de salud mental ya sea historial familiar, tratamiento o interferencia con el trabajo
  -politicas y recursos de la empresa, esto engloba beneficios, opciones de cuidado, atencion medica, anonimatos, abandonos o programas beneficiarios
  -precepciones y actitudes como las consecuencias de la salud mental, consecuencias de la salud fisica, colaboradores, supervisores, salud mental en entrevistas,
  salud mental fisica vs mental
  -Texto libre donde se comentan o se dan ciertas pautas especificas
