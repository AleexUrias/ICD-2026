# Tarea 3: Notebook de regresion

En esta actividad consiste, en utilizar el data set `winequality-red.csv`, para aplicar 2 de las siguientes tecnicas:

- Regresion lineal
- Clasificacion


El dataset cuenta con 1599 registros y 11 atributos, utiliza algunas variables como la acidez, pH, densidad, sulfatos y porcentaje de alcohol.

El objetivo de esta tarea, es comparar el comportamiento de la regresion lineal y de la clasificacion cuando se intenta predecir la calidad del vino.

Partición de datos: 80 % entrenamiento y 20 % prueba, con `random_state=42`.

## Requisitos para la ejecucion del programa

Para ejecutar el archivo `tarea_3` se necesita de los siguientes programas:
- Python
- Pandas
- Numpy
- Scikit-learn

## Intrucciones

Primero descargue el archivo llamado `winequality-red.csv` y adjuntelo en la misma carpeta del notebook, despues abrir el archivo `tarea_3` para ello es necesario ya tener instalado Jupyter Notebook, instalar cualquier archivo complementario que requiera el archivo, y correr las celdas en orden descendente.
