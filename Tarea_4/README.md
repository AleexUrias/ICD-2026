# Tarea 4: Notebook de métricas de clasificación

Esta tarea consiste en construir un modelo que le diga a un banco a quién conviene llamar para ofrecerle un depósito a plazo, y en evaluarlo de forma honesta. Solo 1 de cada 9 clientes acepta, así que llamar a todos es caro. Con los datos de Bank Marketing (Moro et al., 2014), el banco quiere llamar solo a quienes tienen más probabilidad de aceptar.

El dataset cuenta con 41.188 filas y 21 columnas.


## Requisitos para la ejecucion del programa

Para ejecutar el archivo `tarea_4` se necesita de los siguientes programas:
- Python
- Pandas
- Numpy
- Scikit-learn

## Intrucciones

Primero descargue el archivo llamado `bank-additional-full.csv` y adjuntelo en la misma carpeta del notebook, despues abrir el archivo `tarea_4` para ello es necesario ya tener instalado Jupyter Notebook, instalar cualquier archivo complementario que requiera el archivo, y correr las celdas en orden descendente.
