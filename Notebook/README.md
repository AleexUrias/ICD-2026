# Tarea: Procesamiento de un Dataset

En esta actividad consiste, en utilizar el data set Breast Cancer Wisconsin, para aplicar 2 de las siguientes tecnicas
de procesamiento:

- Limpieza de datos
- Aumento de datos
- Extraccion de caracteristicas
- Reduccion de dimensionalidad

El dataset cuenta con 699 registros y 11 atributos, para esta actividad, se decidio utilizar la limpieza de datos y la reduccion de dimensionalidad.

## Requisitos para la ejecucion del programa

Para ejecutar el archivo `tarea_procesamiento` se necesita de los siguientes programas:
- Python
- Pandas
- Numpy
- Scikit-learn

## Intrucciones

Primero descargue el archivo llamado `breast-cancer-wisconsin.data` y adjuntelo en la misma carpeta del notebook, despues abrir el archivo `tarea_procesamiento.ipynb` para ello es necesario ya tener instalado Jupyter Notebook, instalar cualquier archivo complementario que requiera el archivo, y correr las celdas en orden descendente.
